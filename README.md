# Проект с визуальными эффектами «Посмотри в окно»

## Описание проекта
Одностраничный сайт с реализацией анимаций, параллакса и визуальных эффектов. Направлен на изучение современных CSS-возможностей.

## Основной функционал

* CSS-анимации.
* Эффекты при наведении.
* Плавные переходы.
* Нестандартные визуальные решения.

## Используемые технологии

* HTML
* CSS
* Анимации
* Keyframes
* Псевдоклассы

## Полученные навыки

* Создание анимаций.
* Работа с интерактивными эффектами.
